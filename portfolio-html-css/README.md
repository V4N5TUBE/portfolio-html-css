# Portfólio com HTML e CSS

Página de apresentação profissional desenvolvida para praticar os fundamentos de HTML e CSS. O projeto apresenta um texto introdutório, uma imagem e botões de acesso às redes sociais.

## Funcionalidades

- Apresentação profissional com título e descrição.
- Destaque visual em parte do título.
- Botões para Instagram e GitHub.
- Layout organizado com Flexbox.
- Adaptação para computadores, tablets e celulares.
- Efeito visual ao passar o mouse sobre os botões.

## Tecnologias utilizadas

- HTML5
- CSS3
- Flexbox
- Media queries
- Google Fonts

## Estrutura do projeto

```text
portfolio-html-css/
├── index.html
├── style.css
├── imagem.png
└── README.md
```

## Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` no navegador.

Não é necessário instalar dependências.

## Personalização

Para transformar o modelo em um portfólio pessoal:

1. Altere o nome e o texto de apresentação no `index.html`.
2. Substitua os endereços dos botões pelos seus links.
3. Troque `imagem.png` pela sua imagem, mantendo o mesmo nome ou atualizando o caminho no HTML.
4. Modifique as cores no `style.css`, se desejar.
